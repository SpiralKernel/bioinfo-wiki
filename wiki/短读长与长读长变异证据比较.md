# 短读长与长读长变异证据比较

> 更新：2026-10-15；状态：可用；验证范围：官方文档与方法核对；专业命令为模板，本轮未执行该流程。

比较平台时先比较可观察的证据和模型假设，而不是把软件名排成固定优劣顺序。

| 证据 | 能提示什么 | 主要局限 |
|---|---|---|
| 短reads碱基与局部单倍型 | SNV/小Indel及局部复杂事件 | 重复、多重比对与局部表示 |
| 异常读对 | 连接距离或方向改变 | 不自动恢复完整新插入序列 |
| 分裂比对/软剪切 | 断点连接线索 | 比对伪影、缺少唯一侧翼 |
| 长reads跨越 | 插入序列、较长重复与连接 | 平台错误、覆盖、比对与跨越长度 |
| 校正深度 | 剂量变化和大片段CNV | 基线、GC、可比对性、样本组成 |
| 单倍型组装 | 长范围结构与等位序列 | 缺口、塌陷、相位与组装错误 |

同一事件可以由多种证据支持。短读长全基因组、捕获和扩增子的数据覆盖结构不同；训练于某种长读长平台的模型也不能自动适配其他化学/碱基识别版本。

例子先读[人工长读长贯通SV调用与评估](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E4%BA%BA%E5%B7%A5%E9%95%BF%E8%AF%BB%E9%95%BF%E8%B4%AF%E9%80%9ASV%E8%B0%83%E7%94%A8%E4%B8%8E%E8%AF%84%E4%BC%B0)，再结合[结构变异检测的读对分裂读段与组装](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%BB%93%E6%9E%84%E5%8F%98%E5%BC%82%E6%A3%80%E6%B5%8B%E7%9A%84%E8%AF%BB%E5%AF%B9%E5%88%86%E8%A3%82%E8%AF%BB%E6%AE%B5%E4%B8%8E%E7%BB%84%E8%A3%85)与[变异检测软件选择与适用场景](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E6%A3%80%E6%B5%8B%E8%BD%AF%E4%BB%B6%E9%80%89%E6%8B%A9%E4%B8%8E%E9%80%82%E7%94%A8%E5%9C%BA%E6%99%AF)选择任务。该人工案例使用完美reads和map-hifi，不模拟真实HiFi错误分布，也不用于比较平台性能。
