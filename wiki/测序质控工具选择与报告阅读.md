# 测序质控工具选择与报告阅读

> 更新：2026-10-13；状态：可用；验证范围：官方平台资料与原始研究核对；原理及判读，未执行湿实验或平台测序。

按读段、长读长与组装层级选工具，报告汇总不等于自动修复问题。

## 工具在哪个阶段

| 工具 | 常见用途 | 不能推导什么 |
|---|---|---|
| FastQC | read质量、接头、GC等 | 全部通过证明实验成功 |
| fastp | FASTQ预处理和报告 | 默认剪切适合全部文库 |
| MultiQC | 汇总多工具、多样本报告 | 自动完成全部原始分析 |
| NanoPlot | 长read长度、质量、产量图 | 大N50保证组装正确 |
| QUAST | 组装长度和相应参考比较 | 无参考也能发现全部错组装 |
| BUSCO | 选定谱系保守基因完整性 | 全基因组结构和纯度正确 |

支持输入与能力随版本变，应核对实际版本。

## 阅读报告

先核对样本/文库，再看样本间异常、长度、质量和数量。扩增子或小RNA不必符合随机WGS图形，需结合设计解释GC、重复和组成。

保存处理前后数量，过度剪切可丢信息。有效覆盖还需比对和目标区域，原始QC不能给出全部下游质量。

本页未运行这些工具，仅提供选型与报告指南。[人工区间贯通测序指标](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E4%BA%BA%E5%B7%A5%E5%8C%BA%E9%97%B4%E8%B4%AF%E9%80%9A%E6%B5%8B%E5%BA%8F%E6%8C%87%E6%A0%87)不是FastQC或fastp实测。

官方入口：[FastQC](https://www.bioinformatics.babraham.ac.uk/projects/fastqc/)、[fastp](https://github.com/OpenGene/fastp)、[MultiQC](https://docs.seqera.io/multiqc)、[NanoPlot](https://github.com/wdecoster/NanoPlot)、[QUAST](https://quast.sourceforge.net/docs/manual.html)、[BUSCO](https://busco.ezlab.org/busco_userguide.html)。
