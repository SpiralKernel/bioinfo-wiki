# 变异检测软件选择与适用场景

> 更新：2026-10-14；状态：可用；验证范围：官方文档与原始研究核对；专业检测命令为模板，未执行完整真实数据流程。

按测序平台、变异类型、倍性和研究场景选软件，先核对模型与输入，再比较结果。

## 选择表

| 场景 | 代表工具 | 先核对 |
|---|---|---|
| 短读长生殖系SNV/Indel | GATK HaplotypeCaller、bcftools、DeepVariant | 分型模型、参考/资源、倍性、训练适用范围 |
| 长读长小变异 | DeepVariant、Clair3 | HiFi/ONT及碱基识别化学对应模型 |
| 长读长SV | Sniffles、pbsv、DELLY相应模式 | 比对、平台、序列输出及群体模式 |
| 短读长SV | DELLY相应模式等 | 文库、异常区域、读对/分裂证据 |
| 深度CNV | CNVkit、DELLY cnv等 | WGS/捕获/扩增子支持不同，基线与可比对区域 |
| 组装比较/PAV证据 | SyRI等及同源/共线性方法 | 组装完整性、单倍型、参考与特征定义 |
| 串联重复 | ExpansionHunter、TRGT等 | 短读长/HiFi输入和repeat catalog |
| TE插入 | ngs_te_mapper2、McClintock等 | TE库、参考/非参考目标与物种 |
| 体细胞小变异 | Mutect2等 | 配对正常、污染、纯度、低频误差模型 |

本表列代表实现，不是所有工具清单或性能排名。很多名称覆盖多个模块；不能把某模式的支持范围推广到整个软件。人类资源和二倍体训练模型也不能直接当多倍体非模式物种的标准答案。

## 安装后第一件事

记录软件版本、容器tag/digest、模型、参考和资源版本，先用官方小数据测试安装；查看实际`--help`是否与教程接口相同。只记录latest无法保证下次复现。

本轮仅实际执行bcftools1.22；其他工具为文档核对。入口：[DeepVariant](https://github.com/google/deepvariant)、[Clair3](https://github.com/HKU-BAL/Clair3)、[pbsv](https://github.com/PacificBiosciences/pbsv)、[SyRI](https://github.com/schneebergerlab/syri)、[McClintock](https://github.com/bergmanlab/mcclintock)。对应操作由[变异检测分型与提取学习路线](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E6%A3%80%E6%B5%8B%E5%88%86%E5%9E%8B%E4%B8%8E%E6%8F%90%E5%8F%96%E5%AD%A6%E4%B9%A0%E8%B7%AF%E7%BA%BF)连接。
