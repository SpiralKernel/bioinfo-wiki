# 样本表与数据审计实践

> 更新：2026-10-13；状态：可用；验证范围：文档核对；操作需按所用环境验证。

先把样本身份、实验设计和文件位置核对清楚，再进入任何统计分析。

## 建立一张明确的样本表

最低记录 sample_id、subject_id、group、batch 和输入文件路径；按需要增加时间、性别、组织和测量单位。sample_id 表示一次测量，subject_id 标识生物单位，见[生物学重复与技术重复](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%94%9F%E7%89%A9%E5%AD%A6%E9%87%8D%E5%A4%8D%E4%B8%8E%E6%8A%80%E6%9C%AF%E9%87%8D%E5%A4%8D)。

## 按标识符连接

矩阵列与样本表行不能只因数量相同就视为对应。检查空 ID、重复 ID、空白字符、前导零、大小写和未匹配项；重排后再次断言顺序一致。合并应明确是一对一、一对多还是多对一。

```python
matrix_ids = ['S02', 'S01']
metadata = {'S01': {'group': 'control'}, 'S02': {'group': 'treated'}}
assert len(matrix_ids) == len(set(matrix_ids))
assert set(matrix_ids) == set(metadata)
ordered = [metadata[sample] for sample in matrix_ids]
assert ordered[0]['group'] == 'treated'
```

这是可直接运行的最小 ID 对齐例子，不替代对实际样本来源的核验。

## 交接清单

记录输入文件校验值、样本和特征数量、删除原因、缺失编码、组别计数与单位。特别检查批次是否与分组完全重合，见[批次效应与混杂](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%89%B9%E6%AC%A1%E6%95%88%E5%BA%94%E4%B8%8E%E6%B7%B7%E6%9D%82)。

设计示例参照 [Bioconductor 的设计矩阵教程](https://bioconductor.org/packages/release/workflows/vignettes/RNAseq123/inst/doc/designmatrices.html)；完整练习见[合成数据贯通PCA与GWAS](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%90%88%E6%88%90%E6%95%B0%E6%8D%AE%E8%B4%AF%E9%80%9APCA%E4%B8%8EGWAS)。
