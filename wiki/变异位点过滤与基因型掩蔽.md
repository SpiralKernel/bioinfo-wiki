# 变异位点过滤与基因型掩蔽

> 更新：2026-10-14；状态：可用；验证范围：bcftools1.22与HTSlib1.22人工VCF/SAM案例已执行；真实检测性能及其他专业软件未实测。

删位点、标记位点和把单个低质量基因型设为缺失是不同操作，先明确要改变哪一层。

## 跟做入口

先运行[人工VCF贯通变异分类与提取](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E4%BA%BA%E5%B7%A5VCF%E8%B4%AF%E9%80%9A%E5%8F%98%E5%BC%82%E5%88%86%E7%B1%BB%E4%B8%8E%E6%8F%90%E5%8F%96)；每页从项目根目录开始，进入`examples/output/variants`并使用bcftools环境。保留原始文件，本页输出另存。

## FILTER的两种集合

```bash
bcftools view -f PASS -Ov -o only.pass.vcf normalized.vcf.gz
bcftools view -f PASS,. -Ov -o pass.or.unassessed.vcf normalized.vcf.gz
```

本例为15和16条。`.`不代表通过筛选，应在研究设计中决定是否接受未评估记录；不能为了增加位点无说明地合并。

## 单个样本掩蔽

下面8和20仅为人工练习门槛，不是通用推荐：

```bash
bcftools filter -S . -e 'FMT/DP<8 | FMT/DP="." | FMT/GQ<20 | FMT/GQ="."' \
  -Ov -o low.genotypes.masked.vcf normalized.vcf.gz
bcftools +fill-tags low.genotypes.masked.vcf -Ov -o masked.recount.vcf -- -t AC,AN,AF
```

low_site的S01变`./.`，S02仍为0/0，记录仍在，原有LowQual也不会因此变PASS。掩蔽后该记录AC=0、AN=2、AF=0。后续再决定缺失率与位点过滤，缺失绝不能改成参考0/0。

## &和&&的实测反例

unassessed记录中S01深度3/GQ50，S02深度30/GQ8，没有一个样本同时达到门槛：

```bash
bcftools view -i 'FMT/DP>=8 & FMT/GQ>=20' -Ov -o same.sample.vcf normalized.vcf.gz
bcftools view -i 'FMT/DP>=8 && FMT/GQ>=20' -Ov -o cross.sample.vcf normalized.vcf.gz
```

本例前者16、后者17条；后者可由不同样本分别满足。query直接使用样本表达式还可能筛掉输出的样本项，和先用view筛位点再query不同。

真实过滤应结合[变异质量基因型质量与等位平衡](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E8%B4%A8%E9%87%8F%E5%9F%BA%E5%9B%A0%E5%9E%8B%E8%B4%A8%E9%87%8F%E4%B8%8E%E7%AD%89%E4%BD%8D%E5%B9%B3%E8%A1%A1)、倍性与实验设计；频谱/多样性分析不可直接沿用GWAS的MAF/LD剪枝集合。来源：[官方过滤语义](https://samtools.github.io/bcftools/howtos/filtering.html)，实际数值由本项目案例核对。
