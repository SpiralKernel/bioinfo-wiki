# 常见概率分布与生信场景

> 更新：2026-10-13；状态：可用；验证范围：教材、原始研究或官方文档核对；概念与方法说明。

按观测类型和生成假设理解分布，避免给所有组学数据套同一个正态模型。

## 先区分观测分布与统计量分布

表型、计数等是观测变量；t值、卡方值等是由观测计算的统计量。某个检验采用t参考分布，不意味着输入表格里的所有列本身都服从t分布。

| 分布 | 典型含义 | 关键假设或参数 |
|---|---|---|
| Bernoulli | 一次0/1结果 | 成功概率p |
| 二项 | n次试验的成功次数 | 试验独立、相同p；均值np |
| Poisson | 某暴露范围内的计数 | 基本模型下均值与方差均为μ |
| 负二项 | 允许额外离散的计数 | 一种参数化为方差μ+αμ² |
| 正态 | 对称连续波动或模型误差 | 均值与方差；不是所有强度都适合 |
| t | 用估计标准差标准化的某些统计量 | 自由度与模型条件 |
| 卡方 | 某些平方和或渐近检验统计量 | 自由度、渐近近似条件 |
| F | 某些方差或均方比 | 分子与分母自由度 |

## 生信中的例子

二项模型可描述特定条件下的等位计数，但PCR重复、偏倚及额外离散可能破坏简单模型。bulk RNA-seq常需要负二项模型表达生物学变异；不能把原始计数逐基因默认做普通t检验。组成比例、删失时间和空间依赖还需要各自合适的模型。

UMI数据中的零很多，并不单独证明必须使用零膨胀模型。先检查测量机制、条件均值和已有分布是否足以解释零，再选择模型。

## 怎样检查分布假设

检查数据层级、均值与变异关系、残差、极端值和检测机制。做了对数变换，不等于自动满足独立性或同方差。检验模型的条件分布时，要区分组别差异与残差形状。

分布接口见[SciPy统计分布目录](https://docs.scipy.org/doc/scipy/reference/stats.html)；组学模型见[DESeq2原始论文](https://doi.org/10.1186/s13059-014-0550-8)与[广义线性模型与逻辑回归](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%B9%BF%E4%B9%89%E7%BA%BF%E6%80%A7%E6%A8%A1%E5%9E%8B%E4%B8%8E%E9%80%BB%E8%BE%91%E5%9B%9E%E5%BD%92)。
