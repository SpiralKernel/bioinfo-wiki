# 长读长小变异检测与模型选择

> 更新：2026-10-14；状态：可用；验证范围：官方文档与原始研究核对；专业检测命令为模板，未执行完整真实数据流程。

长读长小变异调用仍需匹配平台与训练模型，不能把SV调用器当作全部SNV/Indel流程。

## 输入

记录HiFi或ONT的具体数据/碱基识别来源，参考与比对版本，排序索引、读组、样本、倍性和可检测区域。Sniffles等SV模式与小变异模型回答不同问题，可并行产生互补结果。

## 一个ONT模板

先按[Clair3官方安装与模型说明](https://github.com/HKU-BAL/Clair3)安装匹配版本，获取对应ONT数据模型。下面`run_clair3.sh`需使用实际安装入口；模型目录是待替换示意，不是现成文件：

```bash
run_clair3.sh --bam_fn=sample.sorted.bam --ref_fn=ref.fa \
  --threads=4 --platform=ont --model_path="/你的匹配模型目录" \
  --output=clair3-output
```

这段未运行。不要仅凭同是ONT就任意换模型；化学、碱基识别、是否有特定标签及工具版本会影响支持条件。输出文件名/过滤状态按所用版本说明核对。

## HiFi等其他场景

DeepVariant提供平台/测量场景对应模型；例如其固定r1.9教程列PACBIO与ONT_R104等不同model_type。应固定所用release/容器与模型，不能把旧教程的ONT标签套到所有版本。完整入口：[DeepVariant固定版本示例](https://github.com/google/deepvariant/blob/r1.9/docs/deepvariant-quick-start.md)。本页未安装或执行这些模型。

## 输出检查

核对样本名、GT/质量、区域完整性与参考；之后标准化和分类提取。分层评价SNV、Indel、重复和复杂区域，不以“输出更多位点”判断更好。见[变异评估真值集合与可检测区域](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E8%AF%84%E4%BC%B0%E7%9C%9F%E5%80%BC%E9%9B%86%E5%90%88%E4%B8%8E%E5%8F%AF%E6%A3%80%E6%B5%8B%E5%8C%BA%E5%9F%9F)。
