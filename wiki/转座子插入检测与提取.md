# 转座子插入检测与提取

> 更新：2026-10-15；状态：可用；验证范围：人工TE标记提取已执行；ngs_te_mapper2及真实TE检测未执行。

以家族库和插入连接证据为基础，区分参考与非参考元件，保留两侧支持和未知状态。

## 输入与目标

先记录参考组装、TE家族库、测序布局和目标是参考元件状态还是非参考插入。短reads在元件内可能无法唯一定位，侧翼连接和家族序列提供不同信息。

参考上的重复注释、某条长插入序列与TE家族的匹配、样本间TE插入多态性，是三个需要分别核查的环节。TE库缺失也可能造成漏检。

## ngs_te_mapper2模板

按[官方安装及测试数据](https://github.com/bergmanlab/ngs_te_mapper2)准备环境，先运行其test目录小数据；本轮没有执行。对自己数据的最小接口模板：

```bash
ngs_te_mapper2 -f reads.fastq.gz -l te-library.fasta -r ref.fa \
  -o te-output -p sample
```

多个FASTQ的输入规则、重复掩蔽、可选参考注释及过滤按该版本核对，不按普通read mapper的参数猜。保存日志及参考/非参考输出；相应BED以0-based表示，info字段包含家族、TSD和支持等信息。

## 从结果到表格

建立位置/断点、方向、TE家族、参考状态、两侧连接支持、参考支持、质量与样本字段。群体样本要按兼容插入事件匹配并评估各样本，而不是把没有报告的元件一律填0。

人工VCF中用自定义TEFAMILY=ToyTE标记一条INS，可跟做导出：先运行[人工VCF贯通变异分类与提取](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E4%BA%BA%E5%B7%A5VCF%E8%B4%AF%E9%80%9A%E5%8F%98%E5%BC%82%E5%88%86%E7%B1%BB%E4%B8%8E%E6%8F%90%E5%8F%96)，从根目录进入`examples/output/variants`，在bcftools环境执行：

```bash
bcftools query -i 'INFO/TEFAMILY!="."' \
  -f '%CHROM\t%POS\t%INFO/SVTYPE\t%INFO/TEFAMILY[\t%GT]\n' normalized.vcf.gz
```

得到人工chrToy:1200的INS标记。这不是ngs_te_mapper2的原生字段，也没有证明真实TE身份。将真实结果迁入模板前先改成其实际输出字段/格式。

## 本轮整理入口

长读长分支另见[长读长TE插入证据整理流程](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E9%95%BF%E8%AF%BB%E9%95%BFTE%E6%8F%92%E5%85%A5%E8%AF%81%E6%8D%AE%E6%95%B4%E7%90%86%E6%B5%81%E7%A8%8B)，工具支持按[McClintock与xTea转座子检测选型](https://github.com/SpiralKernel/bioinfo-wiki/wiki/McClintock%E4%B8%8ExTea%E8%BD%AC%E5%BA%A7%E5%AD%90%E6%A3%80%E6%B5%8B%E9%80%89%E5%9E%8B)逐模式核对。本轮未执行TE调用器。
