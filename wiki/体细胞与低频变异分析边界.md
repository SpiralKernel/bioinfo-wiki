# 体细胞与低频变异分析边界

> 更新：2026-10-15；状态：可用；验证范围：官方文档与原始研究核对；专业检测命令为模板，未执行完整真实数据流程。

低频等位证据需要考虑误差、污染与样本组成，不能把生殖系0/1规则直接用于体细胞。

## 先确认场景

肿瘤/正常配对、嵌合、混样或其他低频目标的生成机制不同。reads中ALT比例不直接等于突变细胞比例；拷贝数、纯度、测序偏差和污染都会影响。更高深度也不自动消除系统错误。

## Mutect2最小衔接模板

下面用于展示调用→方向模型→过滤的接口，未执行。BAM中的样本名应核对，NORMAL是待替换的正常样本名：

```bash
gatk Mutect2 -R ref.fa -I tumor.bam -I normal.bam -normal NORMAL \
  --f1r2-tar-gz f1r2.tar.gz -O somatic.raw.vcf.gz
gatk LearnReadOrientationModel -I f1r2.tar.gz -O orientation-model.tar.gz
gatk FilterMutectCalls -R ref.fa -V somatic.raw.vcf.gz \
  --ob-priors orientation-model.tar.gz -O somatic.filtered.vcf.gz
```

真实流程还需按设计处理匹配的germline resource、PoN、污染估计和可检测区域等；不能把这三条命令当所有质量控制完成。保留Mutect2的stats等伴随文件，核对所用版本过滤步骤需要的输入。配对正常与群体正常资源回答不同问题。

## 提取与解释

检查过滤状态、样本级AD/DP/AF及头部定义；记录比较方向与正常样本证据。FORMAT/AF若是reads等位比例，不要用fill-tags计算的群体等位频率代替。没有一条正常VCF记录不能独立证明体细胞来源。

低频检出限需要数据和验证设计支撑，本轮人工杂合案例不评估它。继续[变异质量基因型质量与等位平衡](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E8%B4%A8%E9%87%8F%E5%9F%BA%E5%9B%A0%E5%9E%8B%E8%B4%A8%E9%87%8F%E4%B8%8E%E7%AD%89%E4%BD%8D%E5%B9%B3%E8%A1%A1)、[变异评估真值集合与可检测区域](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E5%8F%98%E5%BC%82%E8%AF%84%E4%BC%B0%E7%9C%9F%E5%80%BC%E9%9B%86%E5%90%88%E4%B8%8E%E5%8F%AF%E6%A3%80%E6%B5%8B%E5%8C%BA%E5%9F%9F)。完整参数与资源见[GATK体细胞教程](https://gatk.broadinstitute.org/hc/en-us/articles/360035531132--How-to-Call-somatic-mutations-using-GATK4-Mutect2)。
