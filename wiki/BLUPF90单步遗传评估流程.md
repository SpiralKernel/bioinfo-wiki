# BLUPF90单步遗传评估流程

> 更新：2026-10-13；状态：可用；验证范围：官方文档与原始研究核对；本页命令模板未在本机运行。

从重编号与参数文件开始，组织方差估计、ssGBLUP预测和结果映射。

## 软件家族与适用任务

BLUPF90是一组遗传评估程序，可处理系谱和基因组信息。当前官方程序页的`blupf90+`整合传统BLUP及REML/AI-REML功能；旧教程的程序拆分与当前发行版不完全相同。本项目未安装运行这一软件家族。

获取程序前核对[官方程序页](https://nce.ads.uga.edu/wiki/doku.php?id=application_programs)的使用条件。当前研究用途发行说明存在分型个体数量等限制，不能默认所有规模和使用场景无限制免费。

## 第一步：定义统计模型与编号

先写清观测性状、固定效应、遗传随机效应、额外环境效应和残差结构，再对照官方示例构造参数文件。RENUMF90负责重编号和相关预处理，保留原始ID、内部编号和基因型编号的映射。不要手动对多个文件分别重新编号后直接拼接。

准备数据列映射、系谱、基因型及分型ID清单。可从[作者维护的逐步教程](https://github.com/masuday/Blupf90TutorialStandard)和[对应数值例子](https://github.com/masuday/data/tree/master/tutorial)选择与模型匹配的起点。具体参数文件与效应数量、列位置、是否重复记录及矩阵设置有关，不能给所有项目共用一份未经核对的完整参数文件。

## 第二步：在官方例子跑通程序链

按所下载发行版的官方说明，先准备 `model.par`，启动：

```bash
renumf90
```

交互提示时输入参数文件名。检查生成的 `renf90.par`、重编号数据、系谱和映射文件后，再按当前CLI格式运行：

```bash
blupf90+ renf90.par
```

当前BLUPF90+默认按BLUP模式求解；`OPTION method VCE`用于方差组分估计，`OPTION method BLUP`用于给定方差求解，具体选项见[BLUPF90+官方说明](https://nce.ads.uga.edu/wiki/doku.php?id=readme.blupf90plus)。这只是程序入口，统计模型、方差估计或已知参数求解的选项仍由参数文件控制。不要把成功退出当成已经进行了所需REML估计。先保存官方例子日志，再一次只替换一类输入并核对计数。

## 基因组与单步步骤

基因组预处理用于检查标记、构建或处理关系矩阵。PREGSF90相关功能在一些现代程序链中会自动调用，需核对版本与日志，避免重复预处理或重复应用矩阵调整。

单步法将系谱A和基因组G组合成统一结构，见[系谱BLUP与单步ssGBLUP](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%B3%BB%E8%B0%B1BLUP%E4%B8%8E%E5%8D%95%E6%AD%A5ssGBLUP)。重点检查G与A22的基准、个体顺序、缩放/混合、逆矩阵设置与分型样本过滤。一旦改变矩阵设置，要重新记录模型，不能只更新输出文件名。

## 结果与辅助程序

| 功能 | 程序家族中的相关入口 | 检查重点 |
|---|---|---|
| 预处理、重编号 | RENUMF90 | 原始ID到内部编号映射 |
| 评估、方差估计 | BLUPF90+等 | 实际运行模式、方差、收敛、解文件 |
| 标记效应回推 | POSTGSF90 | 标记顺序、关系基准与尺度 |
| 基因组预测值应用 | PREDF90等 | 候选基因型与标记方向 |
| 验证与拟合诊断 | VALIDATIONF90、PREDICTF90等 | 可用信息时点、评价量定义 |

按实际发行版选择程序与参数。解文件的效应编号、性状编号和内部ID必须结合参数文件与映射解释。只提取加性遗传项作为相应EBV/GEBV；固定效应、环境项和残差分别保留。

## 迁移到真实项目

先小样本复现，再逐步增加完整系谱和基因型。检查亲本矛盾、谱系循环、丢失分型个体及参数边界。验证采用符合下一世代或候选群体目标的划分，避免用包含测试信息的完整EBV作训练目标。

参考：[官方程序列表](https://nce.ads.uga.edu/wiki/doku.php?id=application_programs)、[程序链说明](https://nce.ads.uga.edu/wiki/doku.php?id=program_sequence)、[BLUPF90说明](https://nce.ads.uga.edu/wiki/doku.php?id=readme.blupf90)。本页是输入与操作路线，完整参数文件需结合官方例子和具体模型填写。
