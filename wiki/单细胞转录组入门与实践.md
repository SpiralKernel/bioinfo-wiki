# 单细胞转录组入门与实践

> 更新：2026-10-14；状态：可用；验证范围：文档核对；完整流程未在本机运行。

从细胞或液滴计数出发，检查质量、探索细胞状态，并将供体层面的比较与细胞聚类区分。

## 输入与路线

输入为计数矩阵、基因和条形码信息、供体及批次表。10x Matrix Market和部分R对象常为基因×细胞；下面Scanpy的AnnData则是细胞×基因，`adata.obs`存细胞/供体注释、`adata.var`存基因注释。导入接口可能已处理方向，应检查shape、细胞和基因名称，不能一律手动转置。理解[UMI与细胞条形码](https://github.com/SpiralKernel/bioinfo-wiki/wiki/UMI%E4%B8%8E%E7%BB%86%E8%83%9E%E6%9D%A1%E5%BD%A2%E7%A0%81)、[生物学重复与技术重复](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%94%9F%E7%89%A9%E5%AD%A6%E9%87%8D%E5%A4%8D%E4%B8%8E%E6%8A%80%E6%9C%AF%E9%87%8D%E5%A4%8D)和[批次效应与混杂](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%89%B9%E6%AC%A1%E6%95%88%E5%BA%94%E4%B8%8E%E6%B7%B7%E6%9D%82)。

先检查每个细胞的计数、检测基因数、线粒体比例及样本分布，再决定空液滴、低质量和双细胞处理。阈值要结合组织、平台与分布，不把一个教程的固定门槛推广到所有组织。

## 官方数据的最小探索

下面需安装 Scanpy 及对应图算法依赖，并联网下载其公开 PBMC 示例；代码尚未在本机执行。它展示矩阵后的探索，不替代完整的液滴识别、双细胞和环境 RNA 处理。

```python
import scanpy as sc
adata = sc.datasets.pbmc3k()
sc.pp.filter_cells(adata, min_genes=200)
sc.pp.filter_genes(adata, min_cells=3)
adata.layers['counts'] = adata.X.copy()
sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)
sc.pp.highly_variable_genes(adata, n_top_genes=2000)
sc.pp.pca(adata)
sc.pp.neighbors(adata)
sc.tl.umap(adata)
sc.tl.leiden(adata, flavor='igraph', n_iterations=2, directed=False)
adata.write_h5ad('pbmc_exploration.h5ad')
```

这里的 200、3、2000 等值属于练习设定。运行前后记录细胞和基因数量，并查看质量指标，不能把这段最小例子视为全部质控完成。

## 结果判断

保存低维坐标、聚类标签、候选标记及原始计数。UMAP 上分离不证明不同细胞类型；聚类分辨率、批次和注释参考影响命名。标记基因分析是细胞群特征探索，供体分组差异应使用考虑供体重复的适当模型，例如适用的 pseudobulk 分析。
