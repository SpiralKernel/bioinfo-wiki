# 群体遗传软件与输入选择

> 更新：2026-10-14；状态：可用；验证范围：原始研究和官方资料核对；方法说明，未运行完整专业分析流程。

按硬分型、基因型似然、完整位点与单倍型要求选择工具，保留各自估计量和分母。

| 问题 | 常见工具入口 | 关键输入与限制 |
|---|---|---|
| VCF操作和筛选 | bcftools、VCFtools | 参考、倍性、过滤、缺失与坐标 |
| PCA/关系/LD | PLINK等 | 分型质量、亲缘、LD与频率 |
| 多样性/dXY | pixy等 | 可检测不变位点与缺失处理 |
| 低覆盖不确定性 | ANGSD及相关工具 | BAM质量、似然模型和mask |
| 祖源 | ADMIXTURE、NGSadmix等 | 硬分型/似然、LD、K与初始化 |
| ROH | PLINK等专门接口 | 密度、允许缺失/杂合、长度与分母 |
| 选择统计 | selscan等 | 按统计量与版本核对分相/未分相模式、距离、编码及标准化 |
| 历史 | PSMC、MSMC2、SMC++ | 各自输入、掩码、率与时间分辨率 |

本表是模型与输入选择，不是已运行的软件列表。命令前先核对版本与官方示例，不能把SNP-only VCF用于所有多样性分母，也不能把硬调用直接当基因型似然。

对比软件先匹配样本、区域、等位方向、缺失、估计量及加权，再解释差异。中间表应能追溯到源文件和过滤规则，见[组学方法比较与敏感性分析](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%BB%84%E5%AD%A6%E6%96%B9%E6%B3%95%E6%AF%94%E8%BE%83%E4%B8%8E%E6%95%8F%E6%84%9F%E6%80%A7%E5%88%86%E6%9E%90)。

官方入口：[bcftools](https://samtools.github.io/bcftools/bcftools.html)、[VCFtools](https://vcftools.github.io/man_latest.html)、[pixy](https://github.com/ksed/pixy)、[ANGSD](https://www.popgen.dk/angsd/index.php/ANGSD)、[selscan](https://github.com/szpiech/selscan)。

## selscan的输入条件按统计区分

默认单倍型统计与显式`--unphased`模式不同，是否支持要核对版本/具体统计。不要把未分相输入作为默认分相输入提交。软件本身不识别祖先/衍生状态；原始iHS/nSL正负取决于用户0/1编码，解释方向需追溯编码来源。

iHS等常按相应频率区间标准化，XP类在群体对比下采用其对应标准化，不能把一种频率分箱规则套到全部统计。缺失、距离文件和每条染色体的处理也按当前手册检查；这些条件来自官方说明，本项目未运行selscan。

多样性/频谱输入不要机械沿用GWAS的MAF过滤与LD剪枝集合，见[等位基因频率杂合度与核苷酸多样性](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E7%AD%89%E4%BD%8D%E5%9F%BA%E5%9B%A0%E9%A2%91%E7%8E%87%E6%9D%82%E5%90%88%E5%BA%A6%E4%B8%8E%E6%A0%B8%E8%8B%B7%E9%85%B8%E5%A4%9A%E6%A0%B7%E6%80%A7)。
