# SNVIndelMNV与复杂变异

> 更新：2026-10-14；状态：可用；验证范围：官方文档与原始研究核对；专业检测命令为模板，未执行完整真实数据流程。

变异类型依赖序列变化与表示方式，VCF一行不一定只含一种替代等位基因。

## 怎样区分

SNV是单个碱基替换。SNP常用于群体多态性语境，软件也常把单碱基替换类别叫SNP；不能仅由一个样本的一条记录确定群体频率。Indel涉及插入或缺失；连续多个碱基替换可表示为MNV/MNP，复杂替换还可能同时包含长度与碱基变化。

| REF → ALT | 直观变化 | 阅读注意 |
|---|---|---|
| A → G | 单碱基替换 | ALT不自动是低频或有害等位 |
| A → AT | 插入T | A通常是锚定碱基，不是新增的序列 |
| AT → A | 删除T | POS可指锚定A，删除碱基本身在后面 |
| AC → GT | 两碱基替换 | 不应默认是两个独立事件 |
| C → G,CA | 一个位置有两种ALT | 一种是替换、一种是插入 |

## 表示与事件

重复序列中的同一Indel可有多个坐标表示；左对齐和最简化帮助比较。拆多等位记录、把复杂等位原子化、真正改变生物学分类，是不同操作。默认拆多等位不会自动把所有MNV变为独立SNV。

SV常用长度门槛作操作性定义，约50 bp是常见约定，具体研究需明确；不是所有SV都能用REF/ALT字符串长度判断。平衡倒位或易位也可能没有净长度增加。
