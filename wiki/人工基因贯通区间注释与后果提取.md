# 人工基因贯通区间注释与后果提取

> 更新：2026-10-14；状态：可用；验证范围：人工基因案例与实际工具输出核对；具体已测范围见正文。

用人工参考和三条转录本实际完成SnpEff构库、bedtools区间核对与按ALT提取后果。

## 下载和依赖

[下载项目ZIP](https://github.com/SpiralKernel/bioinfo-wiki/archive/refs/heads/main.zip)并解压，在含README.md与examples的根目录运行。进入目录见[R与Python路径文件与项目组织](https://github.com/SpiralKernel/bioinfo-wiki/wiki/R%E4%B8%8EPython%E8%B7%AF%E5%BE%84%E6%96%87%E4%BB%B6%E4%B8%8E%E9%A1%B9%E7%9B%AE%E7%BB%84%E7%BB%87)。

基础脚本只用Python标准库；另需Java、SnpEff核心包与bedtools。先按[SnpEff自建数据库与后果解析](https://github.com/SpiralKernel/bioinfo-wiki/wiki/SnpEff%E8%87%AA%E5%BB%BA%E6%95%B0%E6%8D%AE%E5%BA%93%E4%B8%8E%E5%90%8E%E6%9E%9C%E8%A7%A3%E6%9E%90)配置绝对路径SNPEFF_JAR，确认`java -version`和`bedtools --version`。以下适用Linux/macOS或WSL终端：

```bash
export SNPEFF_JAR="/你的实际绝对路径/snpEff.jar"
python3 examples/annotation_demo.py
```

非PATH工具用`--bedtools "/你的路径/bedtools"`或环境BEDTOOLS_BIN，Java可用JAVA_BIN。工具版本、代码与结果见[维护记录](https://github.com/SpiralKernel/bioinfo-wiki/blob/main/maintenance/annotation-workflow-round1-2026-10-14.md)。

## 固定输入与输出

`examples/data/annotation/`有1600bp人工参考、2个基因/3条转录本、CDS和蛋白真值、12条VCF记录（13个ALT），另有边界区间。所有输入均为人工生成，没有真实物种或功能结论。

输出为`examples/output/annotation/`，重复运行覆盖同名生成文件。可用`--output`指定新的独立目录；不要指向输入目录。脚本分build、annotate、intervals、report，只有输入及阶段校验值相符才生成报告。完整源码[annotation_demo.py](https://github.com/SpiralKernel/bioinfo-wiki/blob/main/examples/annotation_demo.py)。

## 实际结果与反例

| 检查 | 预期且实际通过的结果 |
|---|---|
| 数据库序列核对 | 3条CDS、3条蛋白均OK，错误0 |
| 注释单位 | 12记录→21后果行，HIGH6行对应3个记录-ALT |
| 多ALT | multi:T是HIGH；multi:A是MODERATE |
| 转录本差异 | 325对txPlus1为missense，对txPlus2为intron |
| 负链 | 996 G>A对应c.5C>T、p.Ala2Val |
| 区间计数 | gene9对；exon11对，仅7个不同记录 |
| 并列最近 | 两个基因均距离120，保留两者 |

本模型无UTR，构库出现相应提示；标准密码、phase0和短序列是教学限制。解析器不是任意GFF/VCF通用生产工具。

配图另需Matplotlib；按[R包Python包与可复现环境](https://github.com/SpiralKernel/bioinfo-wiki/wiki/R%E5%8C%85Python%E5%8C%85%E4%B8%8E%E5%8F%AF%E5%A4%8D%E7%8E%B0%E7%8E%AF%E5%A2%83)建立项目.venv后执行`.venv/bin/python examples/plot_annotation.py`，图保存到examples/output/annotation-plots。基础注释无需绘图库。

## 自己怎么练习

先复制输入到独立目录，再用`--input-dir`指向副本。把protein.fa一条蛋白改错，构库应拒绝给出验证成功；仅改输入后直接跑report也应因校验值不一致拒绝旧结果。故意失败只在练习副本和独立输出目录进行。

继续用[按基因转录本与后果提取变异](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%8C%89%E5%9F%BA%E5%9B%A0%E8%BD%AC%E5%BD%95%E6%9C%AC%E4%B8%8E%E5%90%8E%E6%9E%9C%E6%8F%90%E5%8F%96%E5%8F%98%E5%BC%82)解释表，再运行[最小注释工作流与Snakemake恢复](https://github.com/SpiralKernel/bioinfo-wiki/wiki/%E6%9C%80%E5%B0%8F%E6%B3%A8%E9%87%8A%E5%B7%A5%E4%BD%9C%E6%B5%81%E4%B8%8ESnakemake%E6%81%A2%E5%A4%8D)。
