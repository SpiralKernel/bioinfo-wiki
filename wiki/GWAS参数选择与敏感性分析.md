# GWAS参数选择与敏感性分析

> 更新：2026-10-13；状态：可用；验证范围：公开小鼠MAF门槛计数、PC0/PC3和chr17背景对照实测；未做全部参数组合的模型重拟合。

参数改变会改变信息、背景与检验集合，敏感性分析应有预先理由和完整记录。

## 先写参数作用与依据

| 选择 | 它改变什么 | 需要的依据 |
|---|---|---|
| 样本/位点缺失门槛 | 可用样本、信息与潜在技术偏差 | 分布、平台、缺失与组别关联 |
| MAF/MAC | 频率范围与统计信息量 | 样本量、性状、计数和检验近似 |
| HWE | 对基因型比例偏离的筛选 | 研究设计、群体结构、病例/对照与技术证据 |
| LD剪枝 | PCA等建模集合中的冗余 | LD范围、群体与任务 |
| PC数量 | 调整的固定效应背景 | 来源、批次、结构与残差诊断 |
| GRM位点与权重 | 随机效应表示 | 质量、频率尺度、家系结构与方法 |
| LOCO或背景排除 | 局部信号进入背景的程度 | 方法实现与染色体对应 |
| 稀疏GRM阈值 | 相关关系保留范围及近似 | 数据相关结构、方法条件与资源 |

参数不应仅为“产生更多显著结果”而选择。记录主分析及有理由的替代设置，报告变化与不稳定处。

## 本例MAF门槛的计数练习

对1410个有表型个体，保持基因型缺失设置一致，只改变MAF筛选的位点计数：

| MAF下限 | 保留位点数 |
|---|---:|
| 0.01 | 9100 |
| 0.05 | 8544 |
| 0.10 | 7757 |

这是实际频率筛选计数，未对三套门槛分别重拟合全部模型。门槛变化后若正式重做GRM、PCA和关联，还应记录哪些背景随之改变；不能假定只是结果表少几行。

## 本例PC与背景的对照

PLINK无PC与PC3配置都用同一批个体和位点，QQ分布明显不同；但PC3仍不能代表家系相关性已解决。GEMMA的全基因组K与排除chr17的K进一步展示背景影响，见[GWAS软件结果比较与一致性检查](https://github.com/SpiralKernel/bioinfo-wiki/wiki/GWAS%E8%BD%AF%E4%BB%B6%E7%BB%93%E6%9E%9C%E6%AF%94%E8%BE%83%E4%B8%8E%E4%B8%80%E8%87%B4%E6%80%A7%E6%A3%80%E6%9F%A5)。

稠密K和稀疏K不只是同一模型的计算优化：保留关系、估计与近似也可能改变。对照时把这些变化明确写出来。

## 怎样设计自己的敏感性分析

先定义主问题及主模型 → 选择少量有科学或质量依据的替代设置 → 固定可比部分并记录不可比部分 → 对齐效应与共同位点 → 查看效应、SE、信号区域和诊断变化 → 报告全部预定结果与解释。

若只保留某次能过阈值的设置，会带来选择偏差。多次探索所得候选仍需要独立验证，不能把探索过程当作预定检验。
